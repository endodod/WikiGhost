# Map Wiki

*Phasmophobia* currently has **14 maps**: 7 small, 5 medium, 2 large. Each map has a randomized weather type, a fixed light limit, and its own set of rooms with one designated Ghost Room.

**Light limits:** Small maps = 9 lights · Medium maps = 8 lights · Large maps = 7 lights (exceeding the limit trips the fuse box).

> **Images:** A few real Fandom CDN image links are included below where they were available directly from the wiki's overview page. For the rest, open the linked wiki page, right-click the main infobox image, "Copy image address," and drop it into the `![]()` placeholder — same CC-BY-SA attribution rule as the item wiki.
