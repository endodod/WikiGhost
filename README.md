# Phasmowiki

Phasmowiki is a Next.js + Tailwind app for Phasmophobia players. It provides a ghost wiki, item and map reference, contract objectives, and guides to help identify and complete investigations faster.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000` in your browser.

## Features

- Ghost Wiki with search and detail views
- Item Wiki and Map Wiki reference pages
- Objectives Wiki and strategy guides
- Game selector for multiple Phasmophobia-like games

## Scripts

- `npm run dev` — start the development server
- `npm run build` — build the production app
- `npm start` — run the built app
- `npm run lint` — run ESLint

## Stack

- Next.js 16
- React 19
- Tailwind CSS 4
- TypeScript
